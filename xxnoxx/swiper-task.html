  loop: false,
  effect: "cube",
  speed: 800,
  autoplay: { delay: 3200, disableOnInteraction: false },

});

任务二 · creative 仿写课堂没讲，AI 教你 · 第七种效果

课堂只讲了 6 种 effect，Swiper 还有第 7 种——creative（自定义变换）。打开官方示例 swiper/demo/257-effect-creative.html，配合 AI 读懂 creativeEffect 的 prev / next 两组 transform 写法，为演示新增第 7 个按钮 [creative 电影墙]。

🎬 creativeEffect 配置（电影墙效果）

creativeEffect: {
  prev: {                              // 上一张（离开的）
    shadow: true,                      // 带阴影
    translate: ["-25%", 0, -300],      // 左移 25%、后退 300px（缩小）
    rotate: [0, 0, -10]                // 绕 Z 轴逆时针转 10 度
  },
  next: {                              // 下一张（进场的）
    shadow: true,
    translate: ["55%", 0, -150],       // 右移 55%、稍微后退
    rotate: [0, 0, 6]                  // 绕 Z 轴顺时针转 6 度
  }
}

🔍 prev / next 的 transform 各控制什么？

prev 控制上一张（当前 slide 的前一张）离开视野时的变换——这里让它向左缩小并倾斜，像电影墙里被推到一边的海报。

next 控制下一张（即将进入的）进场时的变换——这里让它从右侧放大入场，像新海报被推到 C 位。

translate 的百分号是相对于 slide 自身尺寸的（如 "-25%" 即左移自身宽度的 25%）；rotate 的数值是角度（度），改 rotate[2] 为 20 即可让卡片转 20 度。

② 超纲能力：keyboard 键盘控制

课堂未讲过的 Swiper 能力——keyboard 键盘控制。配置代码：

keyboard: {
  enabled: true,            // 启用键盘控制
  onlyInViewport: false     // 即使轮播不在可视区域也响应
}

添加后，可用键盘 ← → 方向键切换 #wySw4 的图片。

🎤 答辩四连问准备

Q1 这段代码什么意思？ keyboard 配置让 Swiper 监听键盘事件，enabled:true 开启，onlyInViewport:false 表示即使轮播不在屏幕可视区域也响应按键。

Q2 AI 第一次给的哪里不对、你改了什么？ AI 第一次只写了 keyboard: true，这在新版 Swiper 中不生效；改为对象形式 { enabled: true, onlyInViewport: false } 后正常工作。

Q3 新参数的作用？ onlyInViewport 控制是否只在轮播可见时才响应键盘，设为 false 可全局响应。

Q4 把 delay 改成指定值？ 把 autoplay.delay 从 3200 改成 1500，翻页速度会变快（每 1.5 秒一张）；改成 5000 则变慢（每 5 秒一张）。
